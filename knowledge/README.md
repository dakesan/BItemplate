# Knowledge Base

Reusable technical knowledge and procedures.

## Purpose

Store protocol documents, workflow guides, and reference materials that can be reused across experiments.

## File Naming

- `workflow_*.md` - Step-by-step procedures
- `protocol_*.md` - Experimental protocols
- `reference_*.md` - Reference information

## Examples

| File | Description |
|------|-------------|
| `workflow_cloning.md` | Molecular cloning workflow |
| `workflow_cell.md` | Cell culture procedures |
| `protocol_pcr.md` | PCR protocol with parameters |
| `reference_primers.md` | Primer database |

## Usage

Link from STEERING.md for quick access. Reference in labnotes when following a procedure.
